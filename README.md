# NOMNOM 🍔

A Swiggy-like food delivery platform with customer and delivery partner modes.

## Tech Stack

Frontend: React + Vite  
Backend: Node.js + Express + MongoDB  
Architecture: Clean Architecture  

## Setup

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

## Features

- Customer ordering system
- Delivery partner dashboard
- Role-based interface
- Real-time tracking (planned)
